# Amex利用明細 → Excel変換ツール

アメリカン・エキスプレスの「ご利用代金明細書」PDFをアップロードすると、取引明細を自動で読み取り、
Excel（.xlsx）形式の一覧表に変換するWebアプリです。

## 特徴

- **サーバー不要・データは外部送信されません**：PDFの読み取りもExcel生成もすべてブラウザ内（JavaScript）で完結します。ネットワーク通信は一切発生しないため、第三者に配布・共有しても安全にご利用いただけます。
- 個人カード・法人カード（本会員/追加カード）の明細に対応。カード名義ごとに取引を区分します。
- 複数月分のPDFをまとめてアップロードして、一つのExcelに統合できます。
- 読み取り結果はその場で編集可能（日付・利用先・カテゴリ・金額を修正、行の削除・追加）。
- 明細書に記載された合計金額と、読み取った合計金額を自動で突き合わせ、一致しているか表示します。

## 処理に時間がかかる理由（重要）

Amexの「ご利用代金明細書」PDFは、各ページが**文字情報を持たない画像（スキャン画像相当、CCITT FAX形式などで圧縮された1ページ約2,000〜3,500ピクセルの大きな画像）**として作成されています。
そのためこのツールは、PDFのテキストを直接読み取るのではなく、ページを画像として描画し、ブラウザ内蔵のOCR（[Tesseract.js](https://github.com/naptha/tesseract.js)）で文字認識しています。

この方式は「データが外部に送信されない」というプライバシー面の安全性を保てる一方、大きな画像のデコード＋OCR処理はCPU負荷が高く、
**1ファイル（数ページ）あたり数十秒〜数分かかることがあります**。処理中はブラウザタブを閉じずにお待ちください。
PCの性能によって所要時間は変わります。ページ数が多い明細書や、性能の低いPCでは特に時間がかかる可能性があります。

OCRは完璧ではないため、**Excel出力前に必ず画面上の一覧表で内容と合計金額をご確認・修正**してください（表は直接編集できます）。

## 使い方

1. `index.html` をブラウザ（Chrome / Edge推奨）で開きます。
2. Amexの「ご利用代金明細書」PDF（1つまたは複数）をドラッグ&ドロップ、または「ファイルを選択」から指定します。
3. 自動で解析され、取引一覧テーブルが表示されます。内容と合計金額を確認し、必要に応じて編集してください。
4. 「Excelをダウンロード」ボタンでファイルを保存します。

### ローカルサーバーで開く場合（推奨）

ブラウザによっては `file://` から直接開くとPDF読み取り用のWorkerスクリプトが正しく読み込まれないことがあります。
その場合は、このフォルダ内で簡易サーバーを起動してからアクセスしてください。

```bash
# Python がある場合
python -m http.server 8000
```

```bash
# Node.js がある場合
npx serve .
```

起動後、ブラウザで `http://localhost:8000`（ポート番号は環境に応じて読み替え）を開きます。

## 第三者への配布について

このフォルダ（`index.html` / `style.css` / `parser.js` / `app.js` / `vendor/`）をそのままコピーすれば、
どなたでも同じように利用できます。GitHub PagesやNetlifyなどの静的ホスティングにそのままアップロードして
公開することも可能です（アップロードされたPDFの中身がサーバーに送信されることはありません）。

## 対応フォーマット・既知の制限

- 標準的な「ご利用代金明細書」のレイアウト（日付＋利用先＋カテゴリ＋金額の並び）を前提に解析しています。
- カード会社側のレイアウト変更や、提携カード（セゾン発行のアメックスなど）で書式が大きく異なる場合、
  一部または全部の取引を検出できないことがあります。その場合は取り込み結果の警告表示に従い、
  手動で行を追加・編集してください。
- OCR（文字認識）の性質上、まれに数字や文字を誤読することがあります。Excel出力前に一覧表で必ずご確認ください。

## 技術構成

- 文字認識(OCR): [Tesseract.js](https://github.com/naptha/tesseract.js)（Apache License 2.0、日本語+英語の学習済みデータを同梱）
- Excel生成: [SheetJS (xlsx)](https://sheetjs.com/)（Apache License 2.0）
- ビルド不要の素のHTML/CSS/JavaScriptのみで構成
